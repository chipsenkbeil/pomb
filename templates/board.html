          Tasks

          Add task

          Click the green + in a column header, type the name and press Enter.

          Delete task

          Open the task and click Delete, or right-click the card and choose Delete.

          Restore task

          Open the Recycle bin from the board menu and click Restore beside the task. A deleted task stays there for 30 days.

          Edit task

          Click a card to open it. Click the name, description or any property to change it.

          Add subtasks

          Open the task and type in "Add subtask...", or use Add > Subtask.

          Change order of tasks inside column

          Drag the card up or down. A column with Task sorting keeps its sort order.

          Move task to other column

          Drag the card to another column, or open the task and use Move.

          Move task to other board

          Open the task and use Move, then pick the board and its column.

          Add due date

          Open the task and use Add > Due date. A due date needs both a date and a time.

          Timer

          Start a pomodoro

          Open a task and use Timer, or press T with the task open.

          Add time manually

          Open the task and use Add > Manual time entry.

          Keyboard shortcuts

          Shortcuts on the board

          A then 1 to 9 adds a task in that column, B boards, F filter, R Reports menu, U show all members, H help, T timer, T then M switches Pomodoro and Stopwatch, Shift + T picks the timer task, S starts, stops or takes a break. Keys do nothing while you type or a dialog is open.

          Shortcuts in an open task

          A add menu, N name, D description, C color, M members, L labels, S subtask, K comment, U due date, F attachment, R relation, E estimate, Y manual time, V Move, T Timer menu, P Reports menu, . More menu, Esc discards changes and then closes, Cmd/Ctrl + Enter saves, Delete deletes the task.
