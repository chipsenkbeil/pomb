API tokens

Tokens let agents and scripts use the Pomb API with Authorization: Bearer pomb_…. A token is shown once when created. Copy it into the agent’s environment (POMB_API_TOKEN). The API reference is at /docs/api.md.

Install the Pomb skill for Claude Code (Codex and other Agent Skills clients read the same file from their own skills directory):

mkdir -p ~/.claude/skills/pomb && curl -fsS {{ base_url }}/skill.md -o ~/.claude/skills/pomb/SKILL.md
